# QA-звіт

Документ оновлюється після кожної фази. Фінальний аудит проводиться у Фазі 10.

## Фаза 5: головна сторінка (самоперевірка)

### Lighthouse (живий сайт на GitHub Pages)

| Профіль | Performance | Accessibility | Best Practices | SEO | LCP | TBT | CLS |
|---|---|---|---|---|---|---|---|
| Mobile (Moto G Power, slow 4G, CPU ×4) | 88 | 100 | 96 | 100 | 3,2 с | 200 мс | 0 |
| Desktop | 100 | 97 → 100 після виправлення п. 12 | 96 | 100 | 0,6 с | 0 мс | 0 |

Best Practices 96: у консолі є 404 на prefetch сторінок, які будуть створені у Фазах 6–7 (послуги, лікарі, ціни тощо). Після Фази 7 має бути 100.

Mobile Performance < 95. Головна має 18 секцій (≈ 2 300 DOM-вузлів, 120 КБ HTML у gzip разом із вбудованим CSS). Подальші кроки заплановано на Фазу 9: розділити payload нижніх секцій, прибрати дублювання даних у RSC, використати `fetchpriority` для hero, перевірити реальні фото (AVIF).

### E2E (Playwright): 16/16 ✅ (desktop 1440 + Pixel 7)

- Запис: 4 кроки → сторінка подяки з імʼям (демо-режим).
- Кнопка «Далі» не перетворюється на submit тим самим кліком (регресійна перевірка).
- Honeypot мовчки відкидає бот-заявку.
- Коротка форма показує зрозумілі помилки українською.
- Квіз вартості дає діапазон ціни.
- EN-версія: `lang="en"`, англійський заголовок.
- Невідомий URL → 404 з пошуком і кнопкою запису.
- Мегаменю: відкривається з клавіатури, Esc закриває й повертає фокус.
- Мобільне меню як діалог, перехід «Болить зараз».
- Нижня панель зʼявляється після hero, «Написати» відкриває месенджери.
- Skip-link переводить фокус на основний вміст.

### Знайдено і виправлено під час самоперевірки

| # | Проблема | Рішення |

| 3 | Горизонтальне переповнення на мобільному в «До / після» і фінальному CTA (сітка без колонок розтягувалася за вмістом) | Глобально: `.grid { grid-template-columns: minmax(0,1fr) }` |
| 4 | Кліки «Записатися» / «Розрахувати вартість» переводили на іншу сторінку замість модалки (next/link перехоплював клік раніше) | Делегування у фазі capture на `window` |
| 5 | Після «Далі» на кроці 3 форма відразу відправлялась і показувала помилки | Різні `key` для кнопок «Далі» / «Записатися» |

| 8 | Велика вартість стилів і розмітки під час завантаження | `content-visibility: auto` для секцій нижче першого екрана; мегаменю й мобільне меню монтуються лише при відкритті; radial-gradient замість `blur()`-плям |
| 9 | Render-blocking CSS | `experimental.inlineCss` |
| 10 | LCP-заголовок перемальовувався після завантаження шрифту | `font-display: optional` для Inter |
| 11 | Windows: prefetch-файли Next потрапляли у вкладені папки (404) | `scripts/postbuild.mjs` (на Linux CI це no-op) |
