# Дизайн-система NaDent

> Жива версія з усіма компонентами і станами доступна на сторінці `/styleguide` (прихована від індексації).
> Джерело правди для токенів: `src/styles/tokens.css`.

---

## 1. Характер бренду

**«Спокійна точність».** Відчуття: дорого, чисто, спокійно, по-людськи тепло. Звідси три правила:
1. **Повітря важливіше за декор.** Великі відступи, один меседж на екран.
2. **Тепло через нейтралі, а не через яскраві кольори.** Теплий пісочний фон секцій замість холодного лікарняного сірого.
3. **Скло потрібне як інструмент, а не для краси.** Воно показує, що елемент плаває над контентом (header, панель, модалка, форма).

## 2. Колір

### 2.1 Порівняння трьох палітр

| | A. **Lagoon** (глибокий синьо-бірюзовий) | B. Champagne (теплий шампань) | C. Graphite + Electric |
|---|---|---|---|
| Акцент | `#0B6E75` | `#8A6636` | `#0071E3` |
| Білий текст на акценті | 6.00:1 ✅ | 5.21:1 ✅ | 4.70:1 (межа) |
| Асоціація | Медицина, чистота, вода, спокій. Не «лікарняний» синій | Люкс, beauty, естетика | Технології, Apple |
| Ризики | Можна пересолити й отримати «аптеку». Лікується теплими нейтралями | Для хірургії та термінових послуг виглядає «салоном краси»; у темній темі каламутний | Надто схоже на Apple і на сотні SaaS; холодний |
| Для кого з персон | Універсальний: Олег, Світлана, Максим, батьки | Анна | Андрій |

**Обрано A (Lagoon) з теплими нейтралями.** Він працює для всіх персон, дає найкращий контраст і вирізняється на ринку, де переважають яскравий бірюзовий і «лікарняний» синій. Теплий пісочний (`#F4F1EC`) перебирає на себе «теплоту» з варіанта B, не конкуруючи з акцентом.

## 3. Типографіка

### 3.1 Шрифти

```css
font-family: -apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", var(--font-inter), "Inter", "Segoe UI", Roboto, sans-serif;
```
- На пристроях Apple працює оригінальний SF Pro (системний, ліцензія не порушується, бо файл шрифту ми не віддаємо).
- На Windows і Android завантажується **Inter Variable** через `next/font` (self-hosted, субсети `latin` + `cyrillic`, `display: swap`, метрики fallback підлаштовуються автоматично, тож CLS немає).
- Перевірка кирилиці: «Ґґ Єє Її Іі ʼ» в Inter мають правильні діакритики і кернінг. Контрольний рядок є на `/styleguide`.
- Inter вмикаємо з OpenType-фічами `cv11` (одноповерхова «а» вимкнена, лишаємо класичну), `ss01` (відкриті цифри). Табличні цифри `tnum` для цін.

### 3.2 Шкала (fluid, `clamp()` між 375 і 1440 px)

| Роль | Розмір | Вага | line-height | letter-spacing |
|---|---|---|---|---|
| Display | 48 → 120 px | 700 | 1.02 | -0.04em |
| H1 | 40 → 72 px | 700 | 1.06 | -0.035em |
| H2 | 32 → 56 px | 600 | 1.08 | -0.03em |
| H3 | 24 → 32 px | 600 | 1.15 | -0.02em |
| Title | 20 → 24 px | 600 | 1.25 | -0.015em |
| Body Large | 18 → 21 px | 400 | 1.5 | -0.01em |
| Body | 17 px | 400 | 1.55 | -0.005em |
| Caption | 14 px | 500 | 1.45 | 0 |
| Overline | 13 px | 600, uppercase | 1.3 | 0.08em |

Від'ємний трекінг дає оптичний ефект «Display»-накреслення. Довжина рядка тексту обмежена `max-width: 68ch`.

### 3.3 Українська типографіка

- Лапки «ялинки», вкладені „лапки“; апостроф `ʼ` (U+02BC) у текстах інтерфейсу. У коді застосовується автоматично функцією `typograph()`.
- Нерозривні пробіли після однолітерних і дволітерних прийменників і сполучників (в, у, з, і, й, та, на, до, за, по, від…) та між числом і одиницею: `15 000 грн`, `2–4 міс`.
- Тире `—` з нерозривним пробілом перед ним; діапазони через en dash `–` без пробілів: `2–4`.
- Тисячі розділяються вузьким нерозривним пробілом `U+202F`.

## 4. Простір, сітка, форми

- **Базова одиниця 4 px.** Шкала: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128, 160.
- **Вертикальний ритм секцій:** `--section-y: clamp(80px, 12vw, 160px)`.
- **Контейнер:** max 1280 px контенту (широкий варіант 1440 px для bento і галерей), поля `clamp(16px, 5vw, 64px)`.
- **Сітка:** 4 колонки (мобільний) / 8 (планшет) / 12 (десктоп), gutter 16 / 24 / 24 px.
- **Радіуси:** `xs 8` (чипи всередині), `sm 12` (поля), `md 16` (малі картки), `lg 24` (картки), `xl 32` (великі картки / bento), `2xl 44` (hero-медіа), `full` (кнопки, пігулки). Для великих карток на WebKit / Chromium вмикаємо `corner-shape: squircle` (прогресивне покращення, без нього звичайне заокруглення).
- **Тіні** (багатошарові, м'які):
  - `--shadow-sm`: `0 1px 2px rgb(0 0 0/.04), 0 1px 1px rgb(0 0 0/.03)`
  - `--shadow-md`: `0 2px 4px rgb(0 0 0/.03), 0 8px 24px rgb(0 0 0/.06)`
  - `--shadow-lg`: `0 4px 8px rgb(0 0 0/.03), 0 24px 64px -8px rgb(0 0 0/.12)`
- **Іконки:** Lucide, stroke 1.5 px, розміри 16 / 20 / 24 px, колір `currentColor`.

## 5. Liquid Glass

Компонент `<GlassSurface variant>`.

| Варіант | Фон (light / dark) | Blur / saturate | Де використовуємо |
|---|---|---|---|
| `regular` | `rgb(255 255 255/.64)` / `rgb(30 30 32/.58)` | 24 px / 180 % | Header, нижня панель, меню |
| `clear` | `rgb(255 255 255/.18)` / `rgb(0 0 0/.18)` | 14 px / 160 % | Декоративні плашки на фото, **лише** разом зі скрімом під текстом |
| `tinted` | `rgb(11 110 117/.78)` / `rgb(94 200 204/.82)` | 20 px / 170 % | Primary-кнопки на фото, активні стани |
| `prominent` | `rgb(255 255 255/.82)` / `rgb(28 28 30/.8)` | 40 px / 200 % | Модалки, bottom sheet, форма запису, cookie-банер |

Шари скла:
1. **Base:** напівпрозорий фон + `backdrop-filter`.
2. **Rim (specular):** `::before` з градієнтною рамкою 1 px (світла зверху-ліворуч → прозора → ледь світла знизу) через `mask-composite`.
3. **Inner light:** `box-shadow: inset 0 1px 0 rgb(255 255 255/.5)`.
4. **Shine:** `::after` з radial-gradient у точці курсора (`--mx`, `--my`). Вмикається тільки на пристроях з `hover: hover`, інтенсивність 6–10 %.
5. **Refraction (Chromium, десктоп):** SVG-фільтр `feTurbulence` + `feDisplacementMap` у `backdrop-filter: url(#glass-refraction)`. Вмикається JS-перевіркою (Chromium, `pointer: fine`, `hardwareConcurrency ≥ 4`) і тільки для header, панелі та hero-плашки. В інших браузерах працює звичайний blur.
6. **Adaptive tint:** секції мають `data-tone="light|dark|media"`, header через `IntersectionObserver` дізнається, що під ним, і перемикає тон скла, щоб зберегти контраст.

Fallback:
- `@supports not (backdrop-filter: blur(1px))` → фон з непрозорістю 0.94.
- `prefers-reduced-transparency: reduce` → повністю непрозорий `--bg-elevated`.
- `prefers-contrast: more` → непрозорий фон + бордер `--fg` 1 px.

**Контраст на склі.** Для тексту на склі поверх фото обов'язковий скрім (градієнт `rgb(0 0 0/.35)` під скляним шаром або непрозорість ≥ 0.64). Найгірший випадок (білий фон під `regular`-склом у світлій темі): ефективний фон ≈ білий, текст `--fg` 16:1. Найгірший для темного тексту: чорне фото під `regular` → ефективний фон ≈ `rgb(163 163 163)` при непрозорості 0.64 → `--fg` дає 7.9:1 ✅. Для `clear` текст допускається лише білий з темним скрімом.

## 6. Motion

- **Easing:** `--ease-out: cubic-bezier(0.22, 1, 0.36, 1)`, `--ease-apple: cubic-bezier(0.28, 0.11, 0.32, 1)`, `--ease-sheet: cubic-bezier(0.32, 0.72, 0, 1)` (як у iOS sheets).
- **Тривалості:** micro 150 мс (натискання), fast 220 мс (hover, стани), base 360 мс (появи), slow 600 мс (scroll-reveal).
- **Springs (Motion):** `snappy` (stiffness 520, damping 40) для кнопок і перемикачів; `smooth` (260, 32) для аркушів і степера.
- **Scroll-reveal:** CSS `animation-timeline: view()` там, де підтримується, з fallback на `IntersectionObserver` (один спільний спостерігач на сторінку).
- **Властивості:** лише `transform`, `opacity`, `filter` (блюр при появі, тільки на десктопі).
- **Reduced motion:** зникають паралакс, масштабування, лічильники (одразу фінальне число), Lenis, бігучий рядок; появи замінюються на миттєві.

## 7. Компоненти

Кожен компонент має стани: default · hover · focus-visible · active · disabled · loading (де доречно) · error / success (для полів).

| Група | Компоненти |
|---|---|
| Дії | Button (`primary`, `secondary`, `ghost`, `glass`, `icon`; розміри `sm 36`, `md 44`, `lg 52` px), Link (inline, arrow) |
| Поля | Input, PhoneInput (+380 маска), Textarea, Select (нативний, стилізований), DatePicker (горизонтальні дні), TimeOfDay, Checkbox, Radio, Switch, SegmentedControl |
| Поверхні | GlassSurface, Card, BentoCard, ServiceCard, DoctorCard, PriceTable, PackageCard |
| Розкриття | Accordion, Tabs, Modal / Sheet (bottom sheet на мобільному), Tooltip, MegaMenu |
| Зворотний зв'язок | Toast, Badge, Rating, ProgressBar, Stepper, Skeleton, EmptyState, ErrorState |
| Медіа | ImageSlot, BeforeAfter, Carousel, VideoSlot, MapFacade |
| Навігація | Header, MobileActionBar, Breadcrumbs, Footer, CommandSearch |
| Правове | CookieBanner |

**Фокус:** `outline: 2px solid var(--accent); outline-offset: 3px;` + для скляних елементів додаткове зовнішнє кільце `0 0 0 6px var(--accent-soft)`. Фокус видно лише при навігації з клавіатури (`:focus-visible`).

**Зони натискання:** мінімум 44×44 px; іконкові кнопки 44 px навіть якщо іконка 20 px.
