# Журнал рішень

Формат: рішення → розглянуті варіанти → чому саме так.

## Продукт і контент

1. **Клініка вигадана (NaDent, Львів, вул. Кульпарківська, 226А).** Замовник дозволив вигадати факти. Усі вигадані дані позначені `DEMO` в `src/config/clinic.ts` і зібрані в `TODO_CONTENT.md`. У footer є рядок «Демонстраційний проєкт…», який вимикається прапорцем `clinic.demoMode`.
2. **Рейтинг і відгуки в schema.org не публікуються**, поки `clinic.rating.verified = false`. Google забороняє розмітку для невідомо звідки взятих рейтингів, а ТЗ вимагає лише реальних даних.
3. **Консультація платна (500 грн, враховується в лікування)**, а не «безкоштовна*». Чесна ціна краще за приховані умови.
4. **Мова інтерфейсу: «усмішка», а не «посмішка».** Нормативна форма, до того ж «посмішка» має відтінок іронії.
5. **Фемінітиви** («лікарка», «ортодонтка») відповідають сучасній нормі та позиціонуванню клініки.

## Архітектура

6. **Хостинг: GitHub Pages, тому Next.js працює в режимі `output: "export"`.**
   Варіанти: (a) Vercel з Server Actions; (b) GitHub Pages зі статикою + зовнішній обробник форм; (c) Netlify Functions. Обрано (b), бо замовник хоче GitHub. Наслідки: немає Server Actions і middleware, форми надсилаються в Cloudflare Worker (`/worker`), а без нього працює демо-режим.
7. **Дві кореневі групи маршрутів `(uk)` і `(en)` замість сегмента `[locale]`.**
   Варіанти: (a) `[locale]` з префіксом `/uk`, що погано для SEO основної мови; (b) один layout з `lang="uk"` для всіх сторінок, що некоректно для англійської; (c) дві групи з власними `<html lang>`. Обрано (c): UA-сторінки лежать у корені без префікса, EN під `/en`. Мінус: перехід між мовами робить повне перезавантаження сторінки (прийнятно, бо це рідкісна дія).
8. **Англійські URL мають англійські слаги** (`/en/services/dental-implants/`), а не транслітерацію. Так вони працюють на англомовні запити.
9. **404: `global-not-found.tsx`** (експериментальний прапорець Next 16). Це єдиний спосіб зробити глобальну 404 при двох кореневих layout. На GitHub Pages вона віддається як `404.html`.
10. **`trailingSlash: true`**: кожна сторінка стає `/path/index.html`, тож працює на будь-якому статичному хостингу без переписувань URL.
11. **Контент у TypeScript-модулях з обома мовами поруч** (`{ uk, en }`), а не в MDX. Типи гарантують повноту перекладу, ціни не дублюються, а міграція в CMS зводиться до заміни функцій `getX(locale)` (див. `README.md`).
12. **Типографіка застосовується централізовано** (`deepTypo`): «ялинки», апостроф ʼ, нерозривні пробіли й тире додаються під час збирання для всього контенту, тож автор може писати звичайним текстом.

## Дизайн

13. **Палітра Lagoon (`#0B6E75`) + теплі нейтралі.** Порівняння 3 палітр наведено в `DESIGN_SYSTEM.md`.
14. **Header у формі «плаваючої капсули»** (як iOS 26 Liquid Glass), а не на всю ширину. Скло краще читається як окремий об'єкт.
15. **Refraction лише в Chromium на десктопі.** Safari не підтримує SVG-фільтри в `backdrop-filter`, а на слабких Android displacement гальмує. Перевірка: `hardwareConcurrency ≥ 4`, `deviceMemory ≥ 4`, `pointer: fine`.
16. **Модалки на нативному `<dialog>`**, а не на бібліотеці: браузер сам дає focus trap, Esc, inert-фон і top layer, а важить це 0 КБ.
17. **Motion (Framer Motion) не підключено**, хоча ТЗ його рекомендує. Усі потрібні анімації (spring-подібні easing, появи, аркуші, степер) зроблено через CSS transitions, `@starting-style` і IntersectionObserver. Це економить близько 35 КБ JS на кожній сторінці й допомагає досягти Performance ≥ 95. Якщо знадобляться складні жести (наприклад, фізика перетягування), пакет `motion` можна додати точково через `next/dynamic`.
18. **Lenis тільки на десктопі з мишею** і ніколи при `prefers-reduced-motion`. На тачскрінах нативний скрол кращий, ніж будь-яка емуляція.

## Форми

19. **Покрокова форма + коротка форма** (порівняння 3 варіантів див. у `02_UX.md`).
20. **Автоперехід між кроками лише при тапі.** Клавіатурна навігація по радіокнопках не перемикає крок (див. UI-аудит, п. 12).
21. **Спам-захист у три шари:** honeypot → Cloudflare Turnstile (режим `interaction-only`, людина капчу майже ніколи не бачить) → rate limit у Worker.
22. **Згода на обробку даних без передвстановленої галочки.** Цього вимагають GDPR і Закон України «Про захист персональних даних».
